# Archive boundaries

`legacy-2023/` contains the original repository material, relocated without rewriting commit history. It is not part of the 2026 GPT web-session campaign. Historical serialized models are not loaded by the verification tools.

`session-notes/` contains the working README, plan, discoveries, handoff and agent instructions at the end of experimentation. These notes retain preliminary claims, evolving stopping decisions and local machine links. They are historical evidence, not current instructions or blanket leakage-free certification. Use the final documents under `docs/` to interpret them.
