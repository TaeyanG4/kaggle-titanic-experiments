# 04. 스킬과 프롬프트로 작업한 방식

[프로젝트 홈](../README.md) / [실험 설계](01-experiment-design.md)

## 스킬은 작업 순서를 정하는 데 사용했다

스킬과 작업 규약은 무엇부터 읽고, 어떻게 비교하고, 어느 파일에 결과를 남길지 정하는 역할을 했다. 프롬프트를 모델 입력으로 사용한 것은 아니다. 생존 예측을 위한 피처와 모델 학습은 Python 코드에서 이루어졌다.

당시 [agents.md](../archive/session-notes/agents.md)에는 plan, discoveries, handoff, README를 먼저 읽기, 버전별 실험 분리, 그룹 타깃 통계의 fold 경계 확인, 제출 전 파일 검사 등이 들어 있다. 설치된 모든 스킬의 원문과 버전을 완전히 보존한 자료는 아니며, 외부 경로의 인증 파일은 공개하지 않았다.

## 반복 작업 흐름

먼저 기존 결과를 읽고 다음에 바꿀 항목을 정했다. GPT가 비교 코드를 만들고 로컬 도구로 실행한 뒤, 점수와 바뀐 예측을 살폈다. 좋지 않으면 실패 이유를 남기고 다른 가설로 넘어갔다. 제출은 대화에서 승인한 범위 안에서 진행했다.

중간에 작업이 끊겨도 파일에 현재 결과가 남아 있으면 다시 읽고 이어갈 수 있었다. 반대로 상태 문서에 과거 판단이 그대로 남으면 이미 끝난 일을 다시 제안하거나, 잠정적인 해석을 확정된 사실처럼 반복하는 문제가 생겼다. 기록을 남기는 것과 기록을 정확히 유지하는 것은 별도 작업이었다.

## 실제로 사용한 지시

다음은 대화 중 사용한 요청의 예다. 전체 대화 원문이나 모든 도구 호출을 빠짐없이 복원한 목록은 아니다.

| 요청 | 의도 | 이어진 작업 |
|---|---|---|
| plan에 적어둬 | 다음 단계를 파일에 남기기 | 계획과 우선순위 갱신 |
| 완료된 후 개선이 되면 알아서 제출해 | 조건부 제출 승인 | 후보 검토 후 제출과 점수 확인 |
| 개선 할만큼 최대한개선하고 더이상할게 없으면 그때 제출해 | 추가 비교 후 제출 | 모델과 검증 분기 확대 |
| 왜 실패 했는가? | 결과보다 원인 확인 | 변경 행과 검증 조건 비교 |
| 계속 진행해봐 | 이전 계획 재개 | 코드 작성, 실행과 로그 확인 |
| 가능성이 있는것들 제출해봐 | 보류 후보 실제 평가 | 마지막 7건 제출 |
| 깃허브 정리하고 마무리하자 | 종료와 문서 정리 | 자료 보존, 설명과 재현 검사 |

질문과 승인은 실험 방향에 영향을 줬다. 로컬 기준으로 보류했던 후보도 나중에 직접 제출하기로 결정했고, 그중 일부가 Public 최고점을 갱신했다. 이런 개입을 제외하고 완전 자동화 성과로 설명하면 실제 작업과 달라진다.

## 자동화한 일과 직접 결정한 일

코드 초안, 반복 설정 실행, 예측 비교, 로그 정리, CSV 생성과 제출 결과 수집은 도구 호출로 처리했다. 목표, 스킬 설정, 추가 질문, 제출 승인과 종료 시점은 직접 결정했다.

로컬 실행 명령을 시작하면 해당 프로세스가 일정 시간 계속 실행될 수는 있었다. 하지만 GPT가 대화 밖에서 계속 다음 가설을 만들고 실행하는 상시 서비스는 아니었다. 진행 상황은 실제 실행 세션과 생성된 파일을 확인해 판단해야 했다.

## 후속 실험에 쓸 작업 지시

아래는 이번 과정을 바탕으로 종료 시점에 정리한 템플릿이다. 실험 시작부터 그대로 사용한 원문은 아니다.

```text
목표와 평가 지표를 먼저 확인한다.
plan, handoff, 이전 실험 결과와 기준 예측 파일을 읽는다.
한 번에 하나의 주요 가설을 바꾸고 같은 split과 모델 seed에서 비교한다.
전처리와 타깃 통계가 어떤 라벨을 사용하는지 명시한다.
OOF, split, 설정, 입력 지문과 예측 파일 해시를 저장한다.
실패한 후보도 결과와 이유를 남긴다.
발견에 사용한 검증과 최종 평가를 구분한다.
외부 제출은 정한 예산과 승인 범위에서만 수행한다.
확인하지 않은 완료 상태나 성능을 사실처럼 기록하지 않는다.
```

다음에는 스킬 버전과 핵심 프롬프트를 처음부터 고정하고, 제출 횟수와 최종 평가를 미리 정하는 편이 낫다. 스킬 자체의 효과를 평가하려면 같은 조건의 대조군도 필요하다. 이번 실험에는 그 대조군이 없었다.
