# Derived experimental evidence

This directory preserves lightweight CSV/JSON results, split manifests, configurations and OOF predictions. OOF tables can include **official training labels**; test predictions are not ground truth. Each result must be interpreted using the corresponding code and validation protocol.

Some derived files with raw passenger names/tickets/cabins, downloaded third-party notebooks, large files and non-tabular logs were intentionally excluded from this publication snapshot. See [excluded-files.json](../docs/evidence/excluded-files.json). They remain in the original local experiment directory and may need regeneration for full historical scripts.

Some older descriptions overstate clean validation or causal conclusions. The [final audit](../docs/03-validation-and-integrity.md) qualifies those claims; keeping an export does not certify its statistical validity.
