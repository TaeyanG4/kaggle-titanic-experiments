# Educational notebooks

The v0-v7 notebooks are preserved with code/Markdown sources and with cell outputs, execution counts and nonessential metadata removed. Advanced v8-v47 work mainly lives in `scripts/`, not one notebook per version.

Notebook cells and generated-script descriptions are historical. Review the [integrity report](../docs/03-validation-and-integrity.md) and each dependency before running them. Output removal reduces repository size and accidental exposure, but is not a code-safety or leakage certification.
