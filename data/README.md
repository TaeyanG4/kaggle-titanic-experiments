# Official data stays local

Obtain `train.csv`, `test.csv`, and `gender_submission.csv` from the official Kaggle Titanic competition after reviewing its terms. These files are not redistributed in the new campaign snapshot.

Recorded input hashes are in [data-fingerprints.json](../docs/evidence/data-fingerprints.json). Setup and extraction instructions are in [reproduction](../docs/05-reproduction.md). Never add Kaggle credentials to this directory or commit them elsewhere.
